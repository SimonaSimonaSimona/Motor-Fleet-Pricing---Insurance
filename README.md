# Motor Fleet Insurance Pricing Analysis (2026)

This repository contains the actuarial pricing script (`PricingAnalysis.py`) used to forecast 2026 claim frequency, expected claim cost, and recommended fleet premium for 100 vehicles based on historical claims data (2022–2025).

## Overview
* **Data:** Historical claim counts, claim severities, and vehicle exposure across 2022–2025.
* **Methodology:** Frequency-severity modeling adjusted for a 5% annual inflation assumption and benchmarked against a competitor quote of 450,000 SEK.
* **Usage:** Run `python PricingAnalysis.py` to reproduce all summary statistics and 2026 pricing figures.
